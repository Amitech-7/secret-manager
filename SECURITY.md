# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button
(Security tab of this repository). Do not open a public issue for a security problem.

## Scope and honesty

- Secrets are encrypted in the browser. The server stores only ciphertext.
- This project has **not** been independently audited. Do not rely on it for secrets you
  cannot afford to lose.
- A forgotten master password cannot be reset. The recovery key is the only fallback.
